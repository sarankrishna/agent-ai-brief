## Ranked technical developments

### 1. AVO demonstrates that long-horizon performance is a full-system property

- **Type:** Research and system announcement. **Evidence:** Primary NVIDIA technical post, dated 2026-08-21.
- **Maturity:** Research prototype and public-set benchmark result.
- **Why it matters:** AVO ran a seven-day GPU-kernel search, explored more than 500 directions, committed 40 kernel versions, and reported up to 10.5% over FlashAttention-4 on evaluated DGX B200 configurations. It completed all 183 ARC-AGI-3 public levels with 6,624 environment actions, compared with 7,542 reported for VISTA using Claude Opus 5.
- **Architecture read:** Persistent external memory, a supervisor for stagnation, executable tools, hardware-grounded evaluation and recovery form a reusable long-horizon runtime.
- **What is not proven:** Results are NVIDIA-reported, the ARC result is only the public set, and the cross-system comparison is not a controlled implementation audit. The GPT-5.6 Sol comparison is limited.
- **Decision:** Read deeply.
- **Source:** [NVIDIA AVO](https://developer.nvidia.com/blog/nvidia-avo-reaches-100-on-arc-agi-3-demonstrating-a-frontier-level-general-purpose-architecture-for-long-horizon-autonomous-agents/)

### 2. Muse Glimmer packages local agent capability around a 24 to 32 GB envelope

- **Type:** Open-weight model release. **Evidence:** Primary Meta AI Research announcement.
- **Maturity:** Weights and documentation available; several runtime integrations are described as arriving shortly.
- **Why it matters:** The release targets always-on local agents, function calling, coding and multimodal input. Meta reports a 30B model under 20 GB at approximately 4-bit, leaving room for KV cache, perception and speculative decoding.
- **Architecture read:** Co-budget weights, cache, perception, drafter and tool runtime. Serving quality depends on the model-runtime pair.
- **What is not proven:** No independent benchmark rerun or workload-specific latency table is provided. Real-time performance is a vendor claim tied to stated hardware.
- **Decision:** Experiment.
- **Source:** [Meta AI Research: Muse Glimmer](https://research.meta.ai/blog/introducing-muse-glimmer-open-agentic-model)

### 3. SkillEvaluator makes agent skills experimentally testable

- **Type:** Evaluation tooling. **Evidence:** Primary NVIDIA post; benchmark snapshot dated 2026-08-12 at commit 738d79e.
- **Maturity:** Open evaluation layer with static, distinctiveness and isolated live tiers.
- **Why it matters:** Across more than 300 skills and two harnesses, NVIDIA reports average gains of 31 points overall and 39 excluding Security. Correctness rose from 46 to 87 and Effectiveness from 39 to 78 in the reported aggregate.
- **Architecture read:** Skills need versioned contracts, provenance, security scanning, negative cases and harness-specific evaluation. Separate task outcome from discoverability, efficiency and security.
- **What is not proven:** Most skills had one attempt, confidence intervals are absent, and token savings can reverse by skill.
- **Decision:** Read deeply.
- **Source:** [NVIDIA SkillEvaluator](https://developer.nvidia.com/blog/evaluating-ai-agent-skill-performance-with-nvidia-skillevaluator/)

### 4. Persistent game worlds are research environments for continual learning

- **Type:** Research partnership and environment strategy. **Evidence:** Primary Google DeepMind post, dated 2026-08-21.
- **Maturity:** Research programme, beginning with an offline EVE Online instance and progressing toward EVE Frontier; not a live-player deployment.
- **Why it matters:** DeepMind identifies continual learning, long-term memory, long-horizon planning and multi-agent dynamics as capabilities difficult to study in static benchmarks.
- **Architecture read:** Persistent environments need durable state, replayable trajectories, policy isolation, multi-agent evaluation and explicit gates before exposure to live users.
- **What is not proven:** This is a programme announcement, not a new benchmark result or demonstrated autonomous performance in EVE.
- **Decision:** Track.
- **Source:** [Google DeepMind: From Atari to EVE Online](https://deepmind.google/blog/from-atari-to-eve-online-building-on-15-years-of-ai-research-in-games/)

## Signals by track

- **Models:** Muse Glimmer makes 30B-class local agent models a direct deployment target.
- **Agents:** AVO reinforces persistent memory, supervision and environment feedback as runtime components.
- **Developer tools:** SkillEvaluator measures skills against fixed harnesses and isolated tasks.
- **Inference:** Reserve memory for KV cache, perception and drafting, not weights alone.

- **Data/evaluation:** With/without treatment designs are stronger evidence than anecdotal prompt improvements, but need replication.
- **Research:** DeepMind is selecting persistent changing environments for continual learning and multi-agent dynamics.

- **Enterprise architecture:** Treat harnesses and skills as versioned runtime dependencies with audit and rollback surfaces.

## Architecture patterns emerging

### 1. Externalized state plus bounded execution
**Evidence:** AVO memory and supervision, plus DeepMind focus on worlds beyond one context window. **Implication:** Persist compact validated state outside model context and resume from checkpoints. **Architect question:** Which facts may advance task state and which require independent verification?

### 2. Capability is an evaluated composition
**Evidence:** AVO model-plus-harness ARC result and SkillEvaluator controlled lift. **Implication:** Benchmark model, harness, tools, skills, environment and policy with ablations. **Architect question:** Can a deployment change use the same task corpus and a repeatable with/without comparison?

### 3. Hardware envelope is part of the agent contract
**Evidence:** Muse Glimmer budget for weights, KV cache, perception and drafting. **Implication:** Measure concurrency, cache and tool-runtime behaviour, not parameter count alone. **Architect question:** What is the quality-latency-cost frontier at the actual workload distribution?
