## Ranked technical developments

### 1. OfficeQA Pro V2 tests grounded-reasoning generalization
**Databricks, 2026-08-18, benchmark release**

OfficeQA Pro V2 contains 90 questions grounded in about 1,400 U.S. Treasury PDFs, roughly 120,000 pages, spanning 233 years. Databricks reports 26.0% average accuracy for default harnesses, 41.1% for competition agents, and up to 60% for Genie with the same underlying models. The architectural signal is that document parsing, hybrid retrieval, tool specialization, and verification can dominate model choice. Vendor-run results require independent replication.

https://www.databricks.com/blog/introducing-officeqa-pro-v2-new-benchmark-enterprise-grounded-reasoning

### 2. Live competition exposes the full-stack nature of enterprise agents
**Databricks, 2026-08-18, evaluation report**

Eleven academic teams applied OfficeQA Pro agents to a held-out corpus. Stanford reached 63.3% using about 100 reusable skills, representation fallbacks, and adaptive verification. The same-model spread between the strongest and weakest teams was 30.4 points. Evaluate the full system, including corpus shift, latency, parsing, retries, and evidence checks.

https://www.databricks.com/blog/evaluating-ai-agents-live-grounded-reasoning-cup

### 3. Zero-trust controls for state-changing agents
**Google Developers Blog, 2026-08-17, security architecture**

Google open-sourced a Customer Support & Returns Agent demo and recommends controls outside the LLM context: per-agent cryptographic signatures for database mutations, gVisor execution with zero network egress and resource limits, and deterministic semantic gateways. Treat prompts as soft constraints and infrastructure as the security boundary. This is a reference architecture, not evidence of deployment readiness.

https://developers.googleblog.com/en/build-zero-trust-ai-agents-with-googles-agent-development-kit/

### 4. AI contrail mitigation moves toward airspace-scale trials
**Google, 2026-08-18, applied AI deployment**

Operation Blue Skies is a 30-month UK-backed trial using AI forecasts and satellite imaging to avoid warming contrails in the eastern North Atlantic corridor. It expects around 10,000 flights during trial hours each year and includes independent evaluation. The key lesson is the transition from model output to a safety-assessed operational control loop.

https://blog.google/innovation-and-ai/models-and-research/google-research/blue-skies/

### 5. PhotoScan is a smartphone body-composition research prototype
**Google Research, 2026-08-17, research announcement**

PhotoScan was trained on more than 35,000 UK Biobank records, fine-tuned on 677 adults, and evaluated on 132 participants. Google reports AUROC 0.760 with demographics plus PhotoScan versus 0.773 with DXA for insulin-resistance classification. This is an investigational prototype; generalization, bias, and clinical validation remain open.

https://research.google/blog/seeing-beyond-bmi-estimating-cardiometabolic-risk-with-smartphone-imagery/

## Research papers and technical reports worth reading

### Policy Iteration with Human Feedback
**arXiv, 2026-08-16, preprint**

PIHF treats a versioned natural-language policy and tool set as the persistent improvement artifact while model weights stay fixed. A critic and clinical expert review trajectories, propose revisions, and retain admission and rollback authority. Reported Recall@1 gains need independent replication.

https://arxiv.org/abs/2608.16831

### TDD-Agent: Test-Driven Reasoning for Code Generation
**arXiv, 2026-08-18, preprint**

TDD-Agent generates tests before implementation, then co-refines tests and code using execution feedback. On the reported RepoEval setup, the ten-iteration system outperformed cited agent baselines across GPT, DeepSeek, and Qwen configurations. Tests become an executable intermediate representation of intent.

https://arxiv.org/abs/2608.16742

### Rule blindness in compliance monitors
**arXiv, 2026-08-18, preprint**

The paper reports that guard-model families and activation probes can track the scenario rather than the supplied governing rule, even when the rule changes. It also audits benchmark degeneracy. Treat this as an evaluation-validity warning.

https://arxiv.org/abs/2608.16852
