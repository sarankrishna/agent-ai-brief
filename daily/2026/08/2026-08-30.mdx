## Ranked technical developments

### 1. AutoSaddler tunes agent harnesses from failure traces

- **Type:** New research submission

- **Evidence:** Tier 1, opened arXiv primary page; results cover GAIA2, SWE-Bench Pro, and Terminal-Bench 2.0.

- **Maturity:** Research.

- **Why it matters:** It diagnoses failed trajectories, patches prompts, tools, and middleware, then selects updates with validation. Reported gains over base harnesses are 9.0, 9.6, and 10.0 points across the three benchmarks.

- **Architecture read:** Harness configuration should be code with regression evaluation, not static prompt text.

- **What is not proven:** The method assumes task success labels and stateless independent tasks. Transfer to uncontrolled work remains open.

- **Decision:** Read deeply

- **Source:** [arXiv](https://arxiv.org/abs/2608.23041)

### 2. Risa uses sparse-MoE routing for agent coordination

- **Type:** New research submission

- **Evidence:** Tier 1, opened arXiv primary page; evaluated on SWE-bench Verified with gpt-oss and Qwen3.6.

- **Maturity:** Research; code and trace release is planned.

- **Why it matters:** Routing arbitration raises the reported gpt-oss macro-average from 44.9% uniform sampling to 48.2%, and reaches 45.2% versus 41.7% on the Qwen condition.

- **Architecture read:** Use novelty during exploration and agreement across independent candidates at commitment.

- **What is not proven:** Results depend on sparse-MoE access and architecture-specific calibration. Generality to dense models is not established.

- **Decision:** Experiment

- **Source:** [Risa paper](https://arxiv.org/abs/2608.22191)

- **Evidence:** Tier 1, official Anthropic research page, August 28, 2026.

### 5. Multi-agent coding needs coordination observability

- **Type:** New research submission

- **Evidence:** Tier 1, opened arXiv primary page; 1,902 instrumented runs plus 244 sealed runs are reported.

- **Maturity:** Research; data and analysis code are stated to be released.

- **Why it matters:** Temporal networks make messages, file reads, and writes measurable. Shared files cut output tokens by about 42% at eight agents on message-heavy work; a named coordinator gave no reliable success gain.

- **Architecture read:** Team traces need topology, shared state, cost, and boundary failures, not only final scores.

- **What is not proven:** The experiments use synthetic Python tasks and show substantial run-to-run variation.

- **Decision:** Read deeply

- **Source:** [When Agents Coordinate](https://arxiv.org/abs/2608.16801)
