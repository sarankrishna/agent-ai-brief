## Three signals that should change your mental model

### 1. Agent performance is a harness-and-environment property
Microsoft Research describes Orchard, a reusable Kubernetes environment service for agent training and evaluation inside Codex, OpenClaw and ZeroClaw. Its reported Orchard-SWE result is 69.7% on SWE-bench Verified with about 3B active parameters. Runtime, isolation, trajectory data and evaluation are part of the capability stack.
[Primary source: Microsoft Research](https://www.microsoft.com/en-us/research/blog/orchard-an-open-framework-for-scalable-agentic-ai/)

### 2. Inference economics are splitting by phase and workload shape
OpenAI reports first measured results from its Jalapeno inference chip across GPT-OSS 120B, DeepSeek R1 and Kimi K2.5. NVIDIA describes Rubin plus Groq LPX as a system separating context processing from latency-sensitive decode. Benchmark complete agent sessions, including KV-cache movement and tool latency, rather than isolated token speed.
[Primary sources: OpenAI](https://openai.com/index/jalapeno-first-results/) and [NVIDIA](https://blogs.nvidia.com/blog/vera-rubin-lpx-spectrum-x-nvlink-fusion/)

### 3. Open-weight models are shipping with agent training as a first-class capability
IBM Granite 4.2 combines reasoning modes, native tool calling and agentic RL in sandboxed environments, with 3B, 8B and 30B Apache 2.0 releases. This is a stronger baseline than treating tool use as a prompt wrapper, but the capability claims remain vendor-authored until independently checked.
[Primary source: IBM Granite](https://huggingface.co/blog/ibm-granite/granite-4-2)

### 2. Microsoft Research releases Orchard for reusable agent environments

## Architecture patterns emerging

### 1. Agent quality depends on reusable environments and durable trajectories
**Evidence:** Orchard separates environment services from training and evaluation; Granite 4.2 uses sandboxed agentic RL and diverse harness trajectories. **Implication:** Preserve executable trajectories, environment metadata and evaluation evidence. **Architect question:** Can a failed trajectory be replayed in an equivalent isolated environment?

### 2. Inference is becoming a phase-aware systems problem
**Evidence:** OpenAI describes local KV state and joint prefill/decode design; NVIDIA describes disaggregated serving and distributed KV caching. **Implication:** Route by context length, decode latency, cache locality and workload value. **Architect question:** Which trace metric predicts useful work per dollar?

### 3. Extensibility surfaces need policy controls before scale
**Evidence:** GitHub exposes MCP servers, plugins, skills and canvases together; Orchard and Granite make tool execution central. **Implication:** Registries need provenance, scopes, versioning, sandbox policy and approvals. **Architect question:** Can discovery remain open while execution stays least-privilege and auditable?
