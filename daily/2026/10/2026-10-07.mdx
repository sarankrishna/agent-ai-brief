## Three signals that should change your mental model

### 1. Agent scale is now a storage and coordination problem, not only a model problem
GitHub reports 7.38 billion commits in September 2026, 3.35 billion monthly pushes, and 3.26 billion Actions runs. Its redesign separates durable repository storage from cache-oriented compute, narrows the coordinated push path to reference updates, and reports up to 35x higher write throughput in internal benchmarks.

**Why it matters:** Thousands of coding agents create write contention, CI fan-out, and maintenance pressure that conventional repository architecture hides.

**Architectural consequence:** Treat agent-generated changes as a high-concurrency distributed-systems workload. Branch isolation, queueing, repository sharding, object storage, and independently scalable read paths become first-class design concerns.

**Direct primary source:** https://github.blog/engineering/architecture-optimization/building-git-infrastructure-for-agent-scale-development/

### 2. Safety boundaries must cover compositions and trajectories
CrowdStrike reports that a classifier with 0% direct bypasses across about 515 tested techniques was bypassed through decomposition and recomposition across 9 of 10 offensive categories. Anthropic is responding from the provider side with verified cyber-access tiers, retention and control requirements, and tier-specific blocking.

**Why it matters:** Per-request filtering can be locally correct while the end-to-end task is unsafe. The security boundary includes the orchestrator, model mix, tool calls, and cross-request state.

**Architectural consequence:** Evaluate sequences, not just prompts. Add provenance, cross-request correlation where possible, least-privilege tools, and human approval at consequential boundaries. Assume attackers can distribute orchestration across providers and local models.

**Direct primary sources:** https://www.crowdstrike.com/en-us/blog/how-attackers-can-bypass-llm-safety-classifiers/ and https://www.anthropic.com/news/cyber-verification-program

### 3. Small multimodal models are moving retrieval to the edge
Google launched EmbeddingGemma 2, a 740M-parameter Apache 2.0 model for text, code, image, video, and audio embeddings. Google reports 128 to 768 dimension truncation through Matryoshka representations, about 191 MB active RAM for quantized text-only weights, and 567 MB for the full multimodal model on a Pixel 11 Pro.

**Why it matters:** Retrieval, routing, and privacy-sensitive indexing can increasingly run locally instead of sending raw media to a central service.

**Architectural consequence:** Separate local embedding and filtering from remote generation. Revisit data residency, offline operation, vector dimensionality, and synchronized index design.

**Direct primary source:** https://blog.google/innovation-and-ai/technology/developers-tools/embeddinggemma-2/

## Architecture patterns emerging

### 1. Separate the control plane from the capability plane
**Evidence:**** Anthropic’s access tiers attach verification and policy to model capability; AWS attaches permissions and confirmation to inference operations; GitHub retains review and branch controls while scaling agent activity.
**Implication:**** Agent systems should route through an explicit control plane for identity, authorization, budgets, retention, approvals, and audit, while model and tool execution remain replaceable capability providers.
**Architect’s question:** Which actions require a human decision, and can the evidence for that decision be reconstructed from resolved tool calls rather than agent summaries?

### 2. Decouple durable truth from elastic execution
**Evidence:**** GitHub separates authoritative repository storage from read-serving compute and maintenance; EmbeddingGemma 2 separates model components and vector dimensions to fit device budgets.
**Implication:**** Keep canonical state and policy durable, but scale caches, workers, embedding paths, and agent execution independently.
**Architect’s question:** Which state is authoritative, and what consistency guarantee does each agent-facing cache actually require?

### 3. Evaluate the whole workflow, not the model response
**Evidence:**** CrowdStrike’s composition attack crosses requests and models; ReviewBench evaluates findings against a multi-source golden set and checks offline movement against production experiments.
**Implication:**** Capability, safety, and quality evaluation should include trajectories, tools, intermediate artifacts, and production-aligned outcomes.
**Architect’s question:** What is the smallest replayable trace that proves both why an agent acted and whether the final result was acceptable?
