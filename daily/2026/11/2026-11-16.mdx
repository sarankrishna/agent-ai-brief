## Ranked technical developments

### 1. Senpi hardens tool-output handling and project-write scope

- **Type:** Agent runtime release; security and reliability fixes.
- **Evidence:** Tier 1, official GitHub release notes, published 2026-11-15 05:53:23 UTC (11:23 IST), within this coverage window.
- **Maturity:** Shipped release v2026.11.15.
- **Why it matters:** The release says Claude subscription tool output is always forwarded to Claude Code marked as tool output, preventing it from being read as a slash command. It also adds optional `expectedCwd` checks to RPC project-write methods, refusing the write when the session is in a different working directory.
- **Architecture read:** This pairs provenance preservation at the tool boundary with an explicit working-directory precondition for project writes. The latter makes location part of the authorization context rather than trusting ambient session cwd.
- **What is not proven:** Release notes do not provide independent security testing, exploit reproduction, coverage details for all adapters, or evidence that every project-write call supplies `expectedCwd`. The cwd check is optional.
- **Decision:** Track.
- **Source:** [Senpi v2026.11.15 release](https://github.com/code-yeongyu/senpi/releases/tag/v2026.11.15)
