**Why it matters:** The release combines a very large sparse model with a long context target and agentic-work positioning. The open-weight date is a stated future plan.

**Decision:** Track

**Open loop:** On 2026-10-15, verify that the weights, configuration, tokenizer, license and reproducible serving path actually appear, then test long-context agent trajectories rather than relying on headline context length.
